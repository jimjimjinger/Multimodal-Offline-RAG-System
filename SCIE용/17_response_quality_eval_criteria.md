# 응답 품질 평가 기준 초안

## 목적

이 문서는 G2, G3, G4 비교군에서 생성된 LLM 답변의 품질을 사람이 일관되게 평가하기 위한 기준이다.

검색 성능 평가는 Recall@k와 MRR로 수행하지만, 실제 실습 안내 시스템의 유용성은 생성 답변의 품질도 함께 확인해야 한다. 따라서 본 연구에서는 검색 성능 평가와 별도로 응답 품질 평가를 수행한다.

## 평가 대상

| 항목 | 내용 |
|---|---|
| 평가 질의셋 | `SCIE용/data/03_question_set_70.csv` |
| 질문 수 | 70개 |
| 비교군 | G2, G3, G4 |
| 모델 | Qwen, Gemma, Llama |
| 평가 단위 | 질문 1개에 대한 모델 답변 1개 |
| 평가 방식 | 사람이 수동으로 1-5점 평가 |

G1은 키워드 기반 검색 baseline이므로 LLM 답변 품질 평가에서는 제외한다. G1은 검색 성능 비교용으로만 사용한다.

## 비교군 정의

| 비교군 | 의미 | 응답 생성 조건 |
|---|---|---|
| G2 | 텍스트 기반 RAG | 텍스트 검색 결과만 LLM context로 제공 |
| G3 | 멀티모달 RAG | 텍스트 검색 결과와 이미지 검색 결과를 함께 제공 |
| G4 | 상황 인지형 멀티모달 RAG | G3에 실습 단계 context map 기반 re-ranking을 추가 |

## 모델 정의

| 모델 | 로컬 모델 ID | 목적 |
|---|---|---|
| Qwen | `qwen2.5:7b` | 기본 7B급 비교 모델 |
| Gemma | `gemma2:9b` | 9B급 비교 모델 |
| Llama | `llama3.1:8b` | 8B급 비교 모델 |

## 평가 항목

응답 품질은 다음 5개 항목으로 평가한다.

| 항목 | 평가 질문 | 핵심 판단 기준 |
|---|---|---|
| 정확성 | 정답 텍스트의 핵심 내용을 맞게 설명했는가? | 매뉴얼 근거와 일치하는지 |
| 구체성 | 실습자가 바로 따라 할 수 있을 정도로 구체적인가? | 메뉴 경로, 수치, 절차, 부품명이 충분한지 |
| 실습 단계 적합성 | 질문의 실습 단계와 맞는 설명을 제공했는가? | 현재 실습 상황에 맞는 안내인지 |
| 안전성 | 위험하거나 잘못된 조작을 안내하지 않는가? | 로봇 안전 기준에 어긋나지 않는지 |
| 이해 용이성 | 초보 학습자가 이해하기 쉬운가? | 표현이 명확하고 불필요하게 복잡하지 않은지 |

## 1-5점 평가 척도

각 항목은 1점부터 5점까지 평가한다.

| 점수 | 의미 | 기준 |
|---:|---|---|
| 5 | 매우 적절 | 정답과 거의 일치하고 실습 안내로 바로 사용 가능 |
| 4 | 적절 | 핵심 내용은 맞고 약간의 보완만 필요 |
| 3 | 보통 | 관련 내용은 있으나 일부 핵심 정보가 부족 |
| 2 | 미흡 | 일부 관련성은 있으나 실습 안내로 사용하기 어려움 |
| 1 | 부적절 | 틀리거나 위험하거나 질문과 무관함 |

## 항목별 세부 기준

### 정확성

| 점수 | 기준 |
|---:|---|
| 5 | 정답 텍스트의 핵심 내용, 수치, 명칭, 절차가 모두 맞음 |
| 4 | 핵심 내용은 맞지만 일부 표현이나 세부 정보가 부족함 |
| 3 | 방향은 맞지만 중요한 조건이나 수치가 빠짐 |
| 2 | 일부 관련 내용은 있으나 핵심 답변이 틀리거나 모호함 |
| 1 | 매뉴얼 근거와 다르거나 질문과 무관함 |

### 구체성

| 점수 | 기준 |
|---:|---|
| 5 | 메뉴 경로, 버튼명, 부품명, 수치, 절차가 구체적으로 제시됨 |
| 4 | 실습에 필요한 주요 정보는 제시되지만 일부 세부가 부족함 |
| 3 | 일반적인 설명은 있으나 실습자가 바로 따라 하기에는 부족함 |
| 2 | 추상적 설명 위주라 실제 조작에 도움이 적음 |
| 1 | 구체적 정보가 거의 없음 |

### 실습 단계 적합성

| 점수 | 기준 |
|---:|---|
| 5 | 현재 실습 단계와 정확히 맞는 page/section/절차를 안내함 |
| 4 | 실습 단계와 대체로 맞지만 일부 주변 단계 설명이 섞임 |
| 3 | 큰 범위에서는 관련이 있으나 현재 단계에 특화되지 않음 |
| 2 | 관련은 있으나 다른 실습 단계의 설명에 가까움 |
| 1 | 현재 실습 단계와 맞지 않음 |

### 안전성

| 점수 | 기준 |
|---:|---|
| 5 | 위험 요소를 피하고 안전 기준에 맞는 안내를 제공함 |
| 4 | 안전상 문제는 없으나 필요한 주의사항이 일부 부족함 |
| 3 | 명백히 위험하지는 않지만 안전 관련 설명이 충분하지 않음 |
| 2 | 오해하면 위험할 수 있는 표현이 있음 |
| 1 | 위험하거나 잘못된 조작을 안내함 |

### 이해 용이성

| 점수 | 기준 |
|---:|---|
| 5 | 초보자가 쉽게 이해할 수 있고 문장이 명확함 |
| 4 | 대체로 명확하지만 일부 용어 설명이 부족함 |
| 3 | 이해는 가능하지만 문장이 길거나 구조가 불명확함 |
| 2 | 설명이 혼란스럽고 핵심을 파악하기 어려움 |
| 1 | 답변을 이해하기 어려움 |

## 최종 점수 계산

최종 응답 품질 점수는 5개 항목의 평균으로 계산한다.

```text
응답 품질 평균 = (정확성 + 구체성 + 실습 단계 적합성 + 안전성 + 이해 용이성) / 5
```

보고서에서는 평균 점수를 다음과 같이 해석한다.

| 평균 점수 | 판정 | 의미 |
|---:|---|---|
| 4.0 이상 | O | 실습 안내로 활용 가능 |
| 3.0 이상 4.0 미만 | △ | 일부 보완 후 활용 가능 |
| 3.0 미만 | X | 실습 안내로 사용하기 어려움 |

## 평가 절차

1. 동일한 70개 질문을 G2, G3, G4 조건에서 실행한다.
2. 각 조건마다 Qwen, Gemma, Llama 답변을 생성한다.
3. 생성된 답변을 `17_response_quality_eval_template.xlsx`에 기록한다.
4. 평가자는 정답 텍스트와 모델 답변을 비교하여 5개 항목을 1-5점으로 평가한다.
5. 평균 점수와 최종 판정을 기록한다.
6. 비교군별, 모델별 평균을 집계한다.

## 평가 시 주의사항

- 검색 결과가 틀려서 답변이 틀린 경우도 최종 응답 품질에는 반영한다.
- 모델이 매뉴얼에 없는 내용을 추측하면 정확성 점수를 낮춘다.
- 안전 관련 질문에서 주의사항이 빠지거나 위험한 조작을 안내하면 안전성 점수를 크게 낮춘다.
- G4의 장점은 실습 단계 적합성에서 드러나야 하므로, 해당 항목을 별도로 해석한다.
- 답변이 길다고 항상 좋은 것은 아니며, 실습자가 바로 사용할 수 있는 명확성이 중요하다.
