# G4 최종 판단 요약

## 목적

이 문서는 G4 상황 인지형 멀티모달 RAG를 논문 실험에서 어떻게 정의할지 정리한 판단 문서이다.

최종 논문에서 사용하는 G4는 정답 실습 단계를 사람이 직접 넣는 방식이 아니라, 질문에서 실습 단계를 추정한 뒤 단계별 page/section/keyword context map으로 재순위화하는 방식이다.

## 최종 비교군

| 구분 | 의미 | 논문 사용 여부 |
|---|---|---|
| G3 | 텍스트 검색, 이미지 검색, page proximity, 텍스트-이미지 매핑 점수를 결합한 멀티모달 RAG | 본문 메인 비교 |
| G4 | 단계 추정 기반 context-aware multimodal RAG | 본문 메인 비교 |
| G4 oracle-stage | 정답 실습 단계가 주어진 상한 성능 | 부록 또는 참고 분석 |

## 최종 검색 성능

| 구분 | Text R@1 | Text R@5 | Text R@10 | Text MRR | Image R@1 | Image R@5 | Image R@10 | Image MRR | Both@5 | Both@10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| G3 멀티모달 RAG | 81.4% | 95.7% | 100.0% | 0.879 | 32.9% | 70.0% | 75.7% | 0.485 | 70.0% | 75.7% |
| G4 상황 인지형 멀티모달 RAG | 85.7% | 95.7% | 100.0% | 0.903 | 37.1% | 75.7% | 87.1% | 0.539 | 75.7% | 87.1% |

## G3 대비 개선 폭

| 지표 | G3 | G4 | 개선 폭 |
|---|---:|---:|---:|
| Text Recall@1 | 81.4% | 85.7% | +4.3%p |
| Text MRR | 0.879 | 0.903 | +0.024 |
| Image Recall@1 | 32.9% | 37.1% | +4.3%p |
| Image Recall@5 | 70.0% | 75.7% | +5.7%p |
| Image Recall@10 | 75.7% | 87.1% | +11.4%p |
| Image MRR | 0.485 | 0.539 | +0.054 |

## oracle-stage 결과의 위치

정답 실습 단계가 주어졌다고 가정하면 Image Recall@5는 81.4%, Image Recall@10은 92.9%, Image MRR은 0.605까지 상승한다. 그러나 이 조건은 실제 사용자가 질문만 입력하는 앱 조건이 아니므로 본문 메인 비교표에서는 제외한다.

논문에서는 oracle-stage 결과를 다음처럼 사용할 수 있다.

- 질문 기반 단계 추정이 정확해질수록 G4 성능이 더 개선될 수 있음을 보여주는 참고 분석
- 부록 또는 discussion에서 제시할 상한 성능
- 메인 성능 주장에는 사용하지 않음

## 최종 판단

논문 본문에서는 G1, G2, G3, G4의 네 가지 비교군을 사용한다. 여기서 G4는 단계 추정 기반 context-aware multimodal RAG로 정의한다.

이렇게 정리하면 다음 장점이 있다.

1. 실제 앱 사용 조건과 일치한다.
2. 정답 실습 단계를 직접 넣는 실험 누수 논란을 피할 수 있다.
3. 교수님이 요구한 context-aware multimodal RAG의 기여를 더 자연스럽게 설명할 수 있다.
4. G4가 G3 대비 Image Recall@5, Image Recall@10, Image MRR을 개선했다는 정량 결과를 본문에서 방어할 수 있다.
