# G4 최종 판단 요약

## 목적

이 문서는 G4 상황 인지형 멀티모달 RAG를 논문 실험에서 어떻게 정의할지 정리한 판단 문서이다.

최종 논문에서 사용하는 G4는 정답 실습 단계를 사람이 직접 넣는 방식이 아니라, 질문에서 실습 단계를 추정한 뒤 단계별 page/section/keyword context map으로 재순위화하는 방식이다.

## 최종 비교군

| 구분 | 의미 | 논문 사용 여부 |
|---|---|---|
| G3 | 텍스트 검색, 이미지 검색, page proximity, 텍스트-이미지 매핑 점수를 결합한 멀티모달 RAG | 본문 메인 비교 |
| G4 | 단계 추정 기반 context-aware multimodal RAG | 본문 메인 비교 |

## 최종 검색 성능

| 구분 | Text R@1 | Text R@5 | Text R@10 | Text MRR | Image R@1 | Image R@5 | Image R@10 | Image MRR | Both@5 | Both@10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| G3 멀티모달 RAG | 78.6% | 94.3% | 100.0% | 0.859 | 38.6% | 74.3% | 84.3% | 0.534 | 74.3% | 84.3% |
| G4 상황 인지형 멀티모달 RAG | 84.3% | 95.7% | 100.0% | 0.894 | 44.3% | 85.7% | 92.9% | 0.608 | 84.3% | 92.9% |

## G3 대비 개선 폭

| 지표 | G3 | G4 | 개선 폭 |
|---|---:|---:|---:|
| Text Recall@1 | 81.4% | 85.7% | +4.3%p |
| Text MRR | 0.879 | 0.903 | +0.024 |
| Image Recall@1 | 38.6% | 44.3% | +5.7%p |
| Image Recall@5 | 74.3% | 85.7% | +11.4%p |
| Image Recall@10 | 80.0% | 87.1% | +7.1%p |
| Image MRR | 0.534 | 0.608 | +0.074 |

가중치 탐색과 최종 평가는 동일한 70개 질의에 기반한 내부 파일럿이므로, 최종 논문에서는 별도 hold-out 검증이 필요하다.

## 최종 판단

논문 본문에서는 G1, G2, G3, G4의 네 가지 비교군을 사용한다. 여기서 G4는 단계 추정 기반 context-aware multimodal RAG로 정의한다.

이렇게 정리하면 다음 장점이 있다.

1. 실제 앱 사용 조건과 일치한다.
2. 정답 실습 단계를 직접 넣는 실험 누수 논란을 피할 수 있다.
3. 교수님이 요구한 context-aware multimodal RAG의 기여를 더 자연스럽게 설명할 수 있다.
4. G4가 G3 대비 Image Recall@5, Image Recall@10, Image MRR을 개선했다는 정량 결과를 본문에서 방어할 수 있다.
