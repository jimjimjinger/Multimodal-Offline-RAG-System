# G4 oracle-stage 참고 평가 결과

## 구현 요약

이 문서는 정답 실습 단계가 주어졌다고 가정한 oracle-stage 참고 평가 결과입니다.
최종 본문에서 사용하는 G4는 단계 추정 기반 G4이며, 이 문서의 수치는 실제 앱 사용 조건의 메인 성능으로 사용하지 않습니다.

oracle-stage G4는 기존 G3 멀티모달 RAG에 실습 단계 문맥 매핑표를 추가한 구조입니다.
질문별 정답 이미지 파일명을 직접 사용하지 않고, `11_stage_context_map_manual`의 단계별 페이지 범위, 섹션 키워드, 본문 키워드를 이용해 텍스트와 이미지 후보를 다시 정렬했습니다.

이번 결과는 정답 텍스트/정답 페이지/정답 이미지 파일명을 사용하지 않고, `11_stage_context_map_manual`의 매뉴얼 기준 단계 문맥표만 사용해 산출한 결과입니다.

## 해석

- oracle-stage G4는 실습 단계가 주어졌을 때 해당 단계와 가까운 페이지 및 키워드를 가진 후보를 상위로 올리는 방식입니다.
- Recall@k는 정답이 후보 안에 들어오는지를 보고, MRR은 정답이 얼마나 앞 순위에 배치되는지를 봅니다.
- 따라서 Recall이 유지되면서 MRR이나 Recall@1이 올라가면, 같은 후보군 안에서 정답을 더 앞쪽으로 정렬한 효과로 해석할 수 있습니다.
