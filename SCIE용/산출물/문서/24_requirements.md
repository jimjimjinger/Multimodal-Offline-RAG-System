# 요구사항 정의서

## 목적

본 문서는 협동 로봇 실습 가이드 시스템의 기능 요구사항과 비기능 요구사항을 정리한다. 석사논문에서는 시스템 설계 장에, SCIE 논문에서는 Proposed Framework 또는 Implementation 섹션에 활용할 수 있다.

## 시스템 목표

본 시스템의 목표는 협동 로봇 실습 매뉴얼을 기반으로 학습자의 질문에 대해 텍스트 근거와 이미지/도식 자료를 함께 검색하고, 로컬 LLM을 통해 실습 단계에 맞는 한국어 안내 응답을 생성하는 것이다.

## 사용자 요구사항

| 사용자 | 요구 |

## 논문 관점 핵심 요구사항

SCIE 논문에서는 모든 기능을 나열하기보다 다음 요구사항을 핵심으로 잡는 것이 적절하다.

1. 텍스트 기반 RAG와 비교 가능한 멀티모달 검색 구조가 필요하다.
2. 정답 텍스트와 정답 이미지를 분리 평가할 수 있는 질의셋이 필요하다.
3. 실습 단계 정보를 반영한 상황 인지형 re-ranking 구조가 필요하다.
4. 검색 성능과 응답 품질을 분리해서 평가해야 한다.
5. 정답 이미지 파일명을 context map에 넣지 않아야 실험 누수를 피할 수 있다.

## 현재 미충족 또는 보완 필요 항목

- rubric 기반 응답 품질 평가는 보조 분석으로만 사용하며, 전문가 평가나 실제 교육 효과 검증으로 주장하지 않는다.
- 8GB 이하 RAM 환경에서의 실제 성능 측정은 별도 검증이 필요하다. 현재 문서에서는 이를 완료된 벤치마크가 아니라 제한 자원 환경을 고려한 설계 요구사항으로 다룬다.
- 같은 page 안의 유사 이미지 구분을 위해 image caption, BBox 주변 국소 텍스트, 이미지 순서 정보가 추가로 필요하다. 현재 BBox는 공간 후보 필터이며 후보 간 직접 점수는 아니다.
