# SCIE 논문 산출물 목록

## 목적

이 폴더는 SCIE/IEEE Access 논문 작성과 교수님 보고에 직접 사용할 최종 산출물만 모아둔 폴더이다. `SCIE용` 루트의 기존 파일들은 작업 과정과 예비 실험 기록을 포함하므로, 보고 또는 논문 작성 시에는 우선 이 `산출물` 폴더를 기준으로 확인한다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `문서/` | 논문 초안, 시스템 설명, 평가 기준, 결과 해석 문서 |
| `엑셀/` | 사람이 확인하기 쉬운 최종 XLSX 산출물 |
| `데이터/` | 재현과 코드 실행에 사용할 CSV 산출물 |

- 09번 G4 초기 context map
