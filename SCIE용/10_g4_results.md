# G4 초기 예비 구현 결과

> 이 문서는 1차 구현 검증용 결과이다. 최종 논문 본문에서는 자동 단계 분류 기반 G4 결과(`30_g4_auto_results.md`)를 사용한다.

## 구현 요약

G4는 기존 G3 멀티모달 RAG에 실습 단계 문맥 매핑표를 추가한 구조입니다.
질문별 정답 이미지 파일명을 직접 사용하지 않고, `09_stage_context_map`의 단계별 페이지 범위, 섹션 키워드, 본문 키워드를 이용해 텍스트와 이미지 후보를 다시 정렬했습니다.

주의: 이번 결과는 1차 구현 검증용입니다. 현재 `09_stage_context_map`은 질의셋의 정답 텍스트 페이지를 근거로 생성한 초안이므로, 논문 본 실험에서는 매뉴얼 기준으로 사전에 확정한 매핑표를 사용하고 평가 후에는 수정하지 않는 절차가 필요합니다.

## 해석

- G4는 실습 단계가 주어졌을 때 해당 단계와 가까운 페이지 및 키워드를 가진 후보를 상위로 올리는 방식입니다.
- Recall@k는 정답이 후보 안에 들어오는지를 보고, MRR은 정답이 얼마나 앞 순위에 배치되는지를 봅니다.
- 따라서 Recall이 유지되면서 MRR이나 Recall@1이 올라가면, 같은 후보군 안에서 정답을 더 앞쪽으로 정렬한 효과로 해석할 수 있습니다.
