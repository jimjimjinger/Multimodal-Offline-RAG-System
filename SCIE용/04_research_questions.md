# SCIE 논문용 연구 질문 정리

## 논문 방향

본 연구는 협동 로봇 실습 매뉴얼을 기반으로, 학습자의 실습 질의에 대해 텍스트 설명과 도식/이미지 정보를 함께 제공하는 상황 인지형 멀티모달 RAG 시스템을 제안한다.

핵심은 단순히 시스템을 구현했다는 점이 아니라, 텍스트 기반 RAG와 비교했을 때 멀티모달 정보와 실습 단계 정보가 검색 성능에 어떤 영향을 주는지를 실험적으로 검증하는 것이다. 응답 품질 평가는 검색 결과가 실제 실습 안내로 연결될 수 있는지를 확인하는 보조 분석으로 둔다.

## 제목 후보

### SCIE 논문 제목 후보

1. A Context-Aware Multimodal RAG Framework for Collaborative Robot Training Guidance
2. Improving Collaborative Robot Training Guidance Using Context-Aware Multimodal Retrieval-Augmented Generation
3. Evaluation of Context-Aware Multimodal RAG for Collaborative Robot Training Manuals

### 국문 석사논문 제목 후보

1. 상황 인지형 멀티모달 RAG 기반 협동 로봇 실습 가이드 연구
2. 협동 로봇 실습 교육을 위한 상황 인지형 멀티모달 검색 증강 생성 시스템 연구

## 핵심 연구 목적

협동 로봇 실습 교육에서 학습자가 매뉴얼을 직접 탐색하지 않고도, 현재 실습 상황에 맞는 설명 텍스트와 관련 도식/이미지를 함께 제공받을 수 있는 RAG 기반 실습 보조 시스템을 구현하고 평가한다. 시스템은 외부 API 의존도를 낮춘 오프라인 실행을 목표로 하지만, 이는 중심 성능 지표가 아니라 배포 및 활용 가능성을 위한 설계 조건으로 다룬다.

## 연구 질문

### RQ1. 협동 로봇 실습 매뉴얼 기반 RAG 시스템은 실습 질의에 필요한 텍스트 근거를 정확히 검색할 수 있는가?

- 목적: 키워드 검색과 텍스트 기반 RAG의 텍스트 근거 검색 성능을 확인한다.
- 비교 대상:
  - G1 키워드 기반 검색
  - G2 텍스트 기반 RAG
- 평가 자료: 70개 질의셋의 정답 텍스트
- 평가 방법:
  - Text Recall@1/5/10
  - Text MRR
  - relaxed text relevance 기준

### RQ2. 텍스트 기반 RAG와 비교했을 때, 이미지/도식 정보를 함께 활용하는 멀티모달 RAG는 관련 시각 자료 검색 성능을 개선하는가?

- 목적: 이미지/도식 검색이 실습 안내에 기여하는지 확인한다.
- 비교 대상:
  - 텍스트 기반 RAG
  - 텍스트 + 이미지/도식 기반 멀티모달 RAG
- 평가 자료: 70개 질의셋의 정답 이미지
- 평가 방법:
  - Recall@1
  - Recall@5
  - Recall@10
  - MRR

### RQ3. 실습 단계 정보를 반영한 상황 인지형 검색은 일반 멀티모달 검색보다 실습 맥락에 더 적합한 이미지/도식 후보를 제공하는가?

- 목적: 질문 기반 실습 단계 추정과 context map 기반 re-ranking이 이미지/도식 후보 순위를 개선하는지 확인한다.
- 비교 대상:
  - 일반 멀티모달 RAG
  - 단계 추정 기반 상황 인지형 멀티모달 RAG
- 평가 자료: 70개 질의셋의 실습 단계 라벨
- 평가 방법:
  - Image Recall@1/5/10
  - Image MRR
  - Both@5/10
  - G4 개선 사례와 실패 사례 분석

### 보조 설계 질문. 외부 API 없이 로컬 벡터 DB와 4-bit 양자화 LLM을 사용하는 구조는 제한된 교육 환경에 적용 가능한 설계 방향인가?

- 목적: 고성능 클라우드 모델 없이도 실습 보조 시스템을 구성할 수 있는 구조인지 설명한다.
- 비교 대상:
  - Qwen 2.5 7B Q4
  - Gemma 2 9B Q4
  - Llama 3.1 8B Q4
- 정리 항목:
  - 외부 LLM API 미사용
  - ChromaDB 기반 로컬 벡터 DB
  - Ollama 기반 로컬 LLM 실행
  - 7B~9B급 Q4 양자화 모델 사용
  - SigLIP 등 무거운 멀티모달 계산의 전처리 단계 분리

이 항목은 논문의 중심 정량 결과가 아니라 시스템 설계 특징으로 제시한다. 현재 정량 실험은 개발용 노트북 환경에서 수행되었으므로, 8GB RAM급 장비에서의 속도, 메모리 사용량, 안정성은 후속 검증 항목으로 남긴다.

## 연구 질문과 실험 산출물 연결

| 연구 질문 | 필요한 산출물 | 현재 상태 |
|---|---|---|
| RQ1 텍스트 검색 성능 | 정답 텍스트, 검색 텍스트 Top-k, Text Recall@k, Text MRR | G1/G2/G3/G4 비교 결과 정리 완료 |
| RQ2 이미지 검색 성능 | 정답 이미지, 검색 이미지 Top-k, Image Recall@k, Image MRR | G3/G4 이미지 검색 결과 정리 완료 |
| RQ3 상황 정보 효과 | 실습 단계 라벨, 단계 추정 결과, G4 re-ranking 결과 | G4 자동 단계 추정 기반 결과 정리 완료 |
| 보조 설계 질문 | 로컬 DB, Q4 양자화 LLM, 오프라인 실행 구조 | 설계 특징으로 정리, 8GB 실측은 후속 검증 |

## 현재 연구 범위

이번 SCIE 논문에서는 다음 범위에 집중한다.

1. 협동 로봇 실습 매뉴얼 기반 데이터셋 구성
2. 텍스트와 이미지/도식 자료의 전처리 및 인덱싱
3. 텍스트 기반 RAG와 멀티모달 RAG 비교
4. 실습 단계 라벨을 활용한 상황 인지형 검색 가능성 평가
5. 로컬 4-bit LLM 기반 응답 품질 보조 분석
6. 오프라인 및 제한 자원 실행을 고려한 시스템 설계 조건 정리
