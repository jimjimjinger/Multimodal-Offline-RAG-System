# 평가 프로토콜

## 목적

본 문서는 검색 성능 평가와 응답 품질 평가의 기준을 정리한다. 논문에서는 Experimental Setup, Metrics, Evaluation 섹션에 활용한다.

## 평가 대상

| 항목 | 내용 |
|---|---|
| 질의 수 | 70개 |
| 비교군 | G1, G2, G3, G4 |
| 응답 생성 모델 | Qwen, Gemma, Llama |
| 검색 평가 대상 | G1/G2/G3/G4 |
| 응답 품질 평가 대상 | G2/G3/G4 |

G1은 검색 baseline이므로 LLM 응답 품질 평가에서는 제외한다. G4는 질문에서 실습 단계를 추정한 뒤 context-aware re-ranking을 적용하는 실제 앱 조건의 제안 방식이다. 정답 실습 단계가 주어진 oracle-stage 결과는 메인 비교에서 제외하고 참고 상한 성능으로만 사용한다.

## 실습 단계 추정 평가

G4는 사용자가 실습 단계를 직접 고르지 않는 조건을 가정한다. 따라서 질문과 실습 단계 context profile 간 BGE-M3 의미 유사도를 비교하여 실습 단계를 추정하고, 이 단계가 정답 실습 단계와 일치하는지 평가한다.

| 지표 | 의미 |
|---|---|
| Top-1 stage accuracy | 1순위 예측 단계가 정답 단계와 일치하는 비율 |
| Top-3 stage accuracy | 정답 단계가 예측 후보 3개 안에 포함되는 비율 |
| G4 적용률 | 기준 점수와 margin 조건을 통과해 G4 re-ranking을 적용한 비율 |

낮은 신뢰도 또는 1위와 2위 후보가 애매한 질문은 G4를 강제로 적용하지 않고 G3 방식으로 fallback한다.

## 검색 성능 평가

### Text Recall@k

Top-k 텍스트 후보 안에 정답 텍스트 또는 정답과 동등한 관련 정보가 포함되는 비율이다. 본 연구의 Text Recall@k는 relaxed 기준으로 산출한다.

```text
Text Recall@k = 정답 텍스트가 Top-k 안에 포함된 질문 수 / 전체 질문 수
```

### Image Recall@k

Top-k 이미지 후보 안에 정답 이미지가 포함되는 비율이다. 본 연구의 Image Recall@k는 strict filename matching 기준으로 산출한다.

```text
Image Recall@k = 정답 이미지가 Top-k 안에 포함된 질문 수 / 전체 질문 수
```

G1과 G2는 이미지 검색을 수행하지 않으므로 Image Recall@k를 계산하지 않는다.

### MRR

정답 후보가 검색 결과에서 얼마나 높은 순위에 위치하는지 평가한다.

```text
MRR = 평균(1 / 정답 후보 순위)
```

정답 후보가 Top-k 안에 없으면 해당 질문의 reciprocal rank는 0으로 계산한다.

### Both@k

Top-k 안에 정답 텍스트와 정답 이미지가 모두 포함되는 비율이다.

```text
Both@k = 정답 텍스트와 정답 이미지가 모두 Top-k 안에 포함된 질문 수 / 전체 질문 수
```

Both@k는 멀티모달 검색 구조인 G3와 G4에서만 계산한다.

## 텍스트 정답 인정 기준

텍스트 검색 평가는 relaxed 기준을 사용한다. 정답 문장과 완전히 동일하지 않더라도 다음 중 하나를 만족하면 정답으로 인정한다.

- 정답 텍스트가 포함된 page 또는 section과 일치
- 기준 답변의 핵심 keyword, 수치, 메뉴명, 기능명이 충분히 포함
- 정답 텍스트와 의미적으로 동일한 절차 또는 설정 정보를 설명

따라서 Text Recall@k와 Text MRR은 exact sentence match가 아니라 정보 검색 성공률에 가까운 지표로 해석한다. 논문에서는 이를 `Text Recall@k (relaxed)`로 명시한다.

## 이미지 정답 인정 기준

이미지 검색 평가는 정답 이미지 파일명을 기준으로 한다.

- 정답 이미지 파일명이 Top-1이면 Image Recall@1 성공
- 정답 이미지 파일명이 Top-5 안에 있으면 Image Recall@5 성공
- 정답 이미지 파일명이 Top-10 안에 있으면 Image Recall@10 성공

같은 page의 유사 이미지가 검색되더라도 정답 이미지 파일명과 다르면 정답으로 인정하지 않는다.

따라서 Image Recall@k와 Image MRR은 `Image Recall@k (strict)` 또는 `strict filename matching` 기준으로 설명한다. Both@k는 relaxed text hit와 strict image hit가 동시에 만족된 경우만 성공으로 계산한다.

## 응답 품질 평가

응답 품질 평가는 G2/G3/G4 조건에서 Qwen, Gemma, Llama 응답을 대상으로 수행한다.

| 평가 항목 | 의미 |
|---|---|
| 정확성 | 정답 텍스트의 핵심 내용과 일치하는가 |
| 구체성 | 메뉴 경로, 버튼명, 설정값, 절차가 충분히 구체적인가 |
| 실습 단계 적합성 | 질문의 실습 단계와 맞는 안내를 제공하는가 |
| 안전성 | 위험하거나 잘못된 로봇 조작을 안내하지 않는가 |
| 이해 용이성 | 초보 학습자가 이해하기 쉬운가 |

각 항목은 1점에서 5점으로 평가한다.

| 평균 점수 | 판정 | 의미 |
|---:|---|---|
| 4.0 이상 | O | 실습 안내로 사용 가능 |
| 3.0 이상 4.0 미만 | △ | 일부 보완 후 사용 가능 |
| 3.0 미만 | X | 실습 안내로 사용하기 어려움 |

## 평가 결과 사용 시 주의사항

- 응답 품질 평가는 rubric 기반 1차 평가이므로 전문가 평가로 표현하면 안 된다.
- 논문에서는 "rubric-based preliminary evaluation"으로 표현하는 것이 적절하다.
- 최종 원고에서는 낮은 점수 사례와 G4 검색 개선 사례를 수동 검토하여 대표 사례로 제시하는 것이 좋다.
